Layout rules used on every screen
  • One primary button per screen, so the next step is obvious.
  • Order: content, choices, main actions, navigation bar last.
  • Danger actions sit in their own row and always ask to confirm.
  • Never more than 5 buttons in a row. Short labels with an icon.
  • Toggles use a label with an On/Off button beside it.
  • The tab bar is always the last row. The current tab is greyed.
  • Small feedback goes in a private popup, so the panel stays calm.
  • Forms (name, code, appeal) open in a Discord modal.
